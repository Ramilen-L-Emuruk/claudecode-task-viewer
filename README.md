# claudecode-task-viewer

Claude Code のタスクを、本文まで含めてブラウザで読むためのローカルビューア。

## なぜこれが要るか

Claude Code のタスクには件名（`subject`）とは別に本文（`description`）があり、そこに調査の
結果・判断の理由・次にやることが書かれる。ところがデスクトップアプリの画面には**件名しか
出ない**。数千文字の本文がタイトル 1 行の裏に隠れる。

このビューアは `~/.claude/tasks/` を直接読んで、本文・依存関係・複数リストの横断表示を行う。

## 使い方

### Windows

**`start.bat` をダブルクリックする。** 初回だけ依存パッケージを自動で取得し、起動したら
ブラウザも開く。閉じるときはコンソールの窓で Ctrl+C。

### コマンドから

```bash
npm install
node server.mjs           # 起動する
node server.mjs --open    # 起動してブラウザも開く
```

表示された `http://127.0.0.1:<ポート>` を開く。既定のポートは 7317 で、埋まっていたら順に
次を試す（`--open` を付けた場合は実際に使ったポートで開く）。

外部にはバインドしない。タスクの本文には作業中のリポジトリの内容がそのまま書かれるため、
同じネットワークの他の端末からは読めないようにしている。

### 環境変数

| 名前 | 既定 | 用途 |
|---|---|---|
| `PORT` | `7317` | 待ち受けポートの始点 |
| `CLAUDE_DIR` | `~/.claude` | `.claude` の場所。別の端末からコピーしたディレクトリを見るときに使う |

## できること

- タスクの一覧と**本文の全文表示**
- 複数リストの横断（切り替え）
- 依存関係（`blockedBy` / `blocks`）を双方向にたどる
- 絞り込み（既定は**未完了**。完了は積み上がるので、開いた直後に見たいのはたいてい残り）
- **依存順の並び替え** ── `blockedBy` の相手を先に置くので、いま着手できるものが上に来る
- 状態の変更（未着手 / 進行中 / 完了）と削除

## できないこと

- **タスクの新規作成**。ID の採番には Claude Code 側との調整が必要なため、作るのは Claude Code
  の役目にしている
- **未完了のタスクに待たれているタスクの削除**。消すと待っている側が着手できないまま残るので
  拒否する（待っている側が既に完了しているなら、もう待っていないので削除できる）

## 動いているセッションと競合しないか

**読み取りではロックを取らない。** Claude Code 本体も一覧・取得ではロックを取らず、ロックを
取るのは作成・更新・割り当て・リセットの 4 つだけなので、読むだけなら干渉しない。

**書き込みでは本体と同じロックを取る。** 同じライブラリ（`proper-lockfile`）で、同じ対象
（タスクのファイル自身）に、同じ設定で掛ける。加えて、画面に表示していた内容と書き込む直前の
内容が一致することを確かめてから書く（一致しなければ 409 を返して中断する）。

書き込む JSON の形式も本体に合わせている（インデント 2・末尾改行なし）。形式が違うと、本体が
読み書きするたびにファイル全体が書き換わったように見えてしまう。

## 自動更新

ファイルの変更を監視して画面に反映する。監視が使えない、または監視が変更を知らせなくなった
場合はポーリング（5 秒間隔）へ切り替え、**切り替えたことを画面の右上に出す**。サーバーとの
接続が切れた場合も同様に表示する。「追従しているつもりで止まっている」状態を作らないため。

## 対応環境

Node.js 18 以上。依存パッケージは `proper-lockfile` 1 つ。
